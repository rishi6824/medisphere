An AI-powered medical diagnosis web application built with Flask.

## Features
- AI Symptom Diagnosis using machine learning
- Medicine Recommendations database
- Hospital Locator with GPS integration
- Medical Chatbot for health queries
- User Authentication system

## Installation
```bash
# Create virtual environment
python -m venv venv
source venv/bin/activate           #linux
venv/bin/activate                  #windows 

# Install dependencies
pip install -r requirements.txt

# Run the application
python app.py
